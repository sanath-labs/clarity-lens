# Live Demo Script (~2 minutes)

1. "Let me show you ClarityLens running live."
   [Open clarity-lens.streamlit.app]

2. "I will paste in a sample claim that has some common reasoning issues."
   [Paste: "Everyone knows this new policy will destroy the economy
   completely, and studies show it will fail, though no source is cited."]
   [Click Analyze]

3. "Notice the color-coded flags - red for absolute language like
   'everyone' and 'completely', and blue flags the unsourced statistical
   claim. This is all done with transparent, rule-based detection - no
   black box."

4. "Below that, the AI generates a neutral summary and the strongest
   opposing viewpoint, so the reader sees both sides rather than a verdict."

5. [Switch to Decision mode]
   "The second mode is for personal decisions. Instead of giving advice,
   it asks Socratic questions to help the user examine their own reasoning."

6. [Switch to History tab]
   "Every analysis is saved locally, with search, sort, and export."

7. "That's the core functionality - all backed by a tested, documented
   codebase with continuous integration."
