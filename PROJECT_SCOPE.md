# Project Scope

ClarityLens is scoped as a beginner-to-intermediate final-year capstone
project. Current features:
- Sentence-level flag detection (absolute language, emotional language, missing source)
- AI-generated neutral summary and opposing viewpoint (Groq API)
- Personal Decision Mode with Socratic questioning
- Persistent history with search, sort, delete, and CSV export
- Automated testing via pytest and GitHub Actions CI

Out of scope for this version: multi-language support, user accounts,
cloud deployment at scale, mobile app.
