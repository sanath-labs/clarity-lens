# Contributing to ClarityLens

This is currently a solo academic project built as part of a final-year
Information Science capstone. Contribution guidelines will be expanded
if the project opens up to collaborators.

## Development setup
1. Clone the repo
2. Create a virtual environment and activate it
3. Install dependencies: pip install -r requirements.txt
4. Copy .env.example to .env and add your Groq API key
5. Run the app: streamlit run app.py

## Code style
- Add docstrings to all functions
- Add type hints where practical
- Write tests for new logic in the tests/ folder
